# Vazirmatn webfont

`Vazirmatn-Variable.woff2` is the official variable webfont from Vazirmatn
version 33.003. The font supports the complete variable weight range; TaskFlow
uses weights 400, 500, 600, and 700.

Source: <https://github.com/rastikerdar/vazirmatn/tree/v33.003>

The font is distributed under the SIL Open Font License 1.1. The complete
license text is retained in `OFL.txt`.
